# YouGile UI Automation Tests

Проект автоматизации UI-тестирования для системы управления проектами YouGile. 
Включает в себя ключевые бизнес-сценарии: работу с канбан-досками, корпоративным мессенджером, воронкой продаж и авторизацией.

## 🛠 Стек технологий
* **Python 3.11+**
* **Pytest** — фреймворк для написания и запуска тестов.
* **Playwright** — инструмент для UI-автоматизации.
* **Allure** — генерация отчетов о тестировании.
* **Requests** — для подготовки данных (API).

## 📂 Структура проекта
* `config/` — файлы конфигурации (JSON).
* `pages/` — Page Object Model (POM) классы для страниц.
* `tests/` — непосредственно автотесты и фикстуры.
* `requirements.txt` — зависимости проекта.
